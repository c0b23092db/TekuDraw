# Teku Draw
**大学の卒業研究で開発している「物体追跡研究用データセット作成シミュレータ」**

## 動作環境
- [Godot Engine](https://godotengine.org/ja/)の**4.7.2**を使用できる環境
- Windows 11

## 操作方法
[使い方.md](./README/使い方.md)を参照してください。

## 3Dモデル
デモでは[Mixamo](https://www.mixamo.com/)のモデルを使用しています。
`.*_Idle`と`.*_Walking`の`fbx`ファイルを使用します。
- Leonard_Idle
- Leonard_Walking
- Louise_Idle
- Louise_Walking

未検証動作として、歩行と停止に類する`fbx`ファイルであれば、他のモデルでも動作する可能性があります。
