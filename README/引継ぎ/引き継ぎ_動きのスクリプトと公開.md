## 2026-10-18 にやったこと

### 動きのスクリプト（研究室の動物の研究向け）
動物体の「動き」で、`./.config/motion/*.gd` を選べる。コンパイル不要で、書き出したアプリでも exe の隣の `.config/motion/` に置けば読める。
- API の説明は [.config/motion/README.md](../../.config/motion/README.md)（使う人と AI に渡す前提で書いた）。見本は [random_walk.gd](../../.config/motion/random_walk.gd)。
- 仕組み: [Motion.gd](../../script/core/Motion.gd)
  - `choices()`（ドロップダウンの中身）、`compile()`（`GDScript.new()` に `source_code` を入れて `reload()`）、`fields()`（スクリプトの `FIELDS`）、`params()`（動物体の値を型・範囲で直す）。
  - `World`（スクリプトに渡す窓口）: `nearby`、`obstacles`、`is_blocked`、`reachable`、`lines()`、`bounds`、`random_goal`。
- 本体（[SimulationManager3D.gd](../../script/SimulationManager3D.gd)）:
  - 状態 `SCRIPTED` を足し、`_update_scripted()` が毎刻み `step(me, world, rng, delta)` を呼ぶ。`me` は Walker そのもの（`position`・`memory`・`param` を足した）。
  - `step()` が返すのは行き先と速さだけ。よける動き、障害物の迂回、列を横切るときの待ち・譲り、二本の経路は、今までどおり本体が受け持つ。
  - 戻り値 `{"line": true}` で組み込みの列へ、`{"respawn": true}` で現れ直す。Dictionary 以外を返したら、その場で止めて一度だけ警告する。
- 決めたこと:
  - **列に並ぶ動きは本体に残した**（組み込み。動きの値 `""`）。列は人どうしのやりとり（順番・譲り合い・通り抜けない）でできていて、外に出すと今後の調整がしにくくなるため。外に出したのは、1 人で完結するランダムに歩く動きだけ。
  - 「列に並ぶ」チェックボックス（`join_line`）は「動き」に置き換えた。古いファイルで `join_line = false` の動物体は、読み込むと `random_walk.gd` になる（`SceneStore._read_object`）。
  - 「列に並ぶ」なのに列の線が無い動物体は、人を出さずにコンソールで知らせる（前はランダムに歩いた）。
  - 全体の設定「目的地までの最短距離」は `random_walk.gd` の項目に移した。
  - スクリプトの設定値は、動物体のファイルに同じセクションの平たいキーで保存する。全体の設定と同じ名前は使えない（`Motion.fields` が警告して外す）。
- リプレイ: 使ったスクリプトのソースを `[motion] sources = [[名前, ソース], …]` に保存する。再生するときは、`./.config/motion` ではなく保存したソースを使う。
- 設定画面（[SettingsDialog.gd](../../script/scene/SettingsDialog.gd)）: `"choices"` の項目は OptionButton。動きを変えると `fields_for` で項目を作り直す（入力中の値は残す）。スクリプトの項目は、動物体のページの下に、スクリプトの `LABEL` の見出しをつけて出る（`Motion.fields()` が最初の項目に `"heading"` を付ける）。

### 描画画面
- 線は 3 種類: 左ドラッグで列、右ドラッグで出現地（長い破線）、Shift+左ドラッグで目的地（短い点線）。1 回クリックだけならその 1 点になる。
- 「×列」「×出現地」「×目的地」で、選んでいる動物体の線を消す。
- 動物体の設定に「空いた列には近い所から入る」（`join_nearest`、既定オン）。オンは店の扉に入るような動き、オフは決められた列に並ぶ動き（線の始点まで行く）。

### 床
- 「床の画像」の既定値は空。空・読めないときは、シーンのままの白い床（読めないときは警告を出す）。
- ユーザーの `.config/general.toml` は `floor_texture_path = "res://objects/image"`（フォルダ）になっていて、起動すると警告が出る。

## 気をつけること
- 動きのスクリプトの乱数は、渡された `rng` だけを使う決まり（README に書いた）。`randf()` を使われると、リプレイが再現しない。本体では防げない。
- `World.nearby()` は全員を調べる（人数の2乗）。500 人を超えて重くなったら格子で区切る（`ponytail:` コメントあり）。
- スクリプトは何でも実行できる。自分たちで書いたファイルだけを使う前提。
- FBX を実行中に読むと、1 ファイル約 1.5 秒かかる（`res://` のモデルは取り込み済みなので速い）。
- `taskkill //IM godot.exe` はユーザーのエディタも止める。ヘッドレスのテストは `timeout` を付けて実行する。
