## シミュレーション画面
左上に操作方法が書いています。Godotのカメラ操作を基準としています。

- 右ドラッグ: 回転（カメラ軸）
- 中クリック: 回転（中央軸）
- 右クリック + WASD: 移動
- 右クリック + QE: 上下移動
- 中クリック + Shift: 平行移動
- ホイール: ズームイン・アウト
- `+` / `-`: 時刻を30分進める / 戻す
- Enter: 描画画面へ戻る
- Space: UI描画を切り替える

カメラ位置を固定することで、エディター画面に戻ってもカメラ位置を保持することができます。
