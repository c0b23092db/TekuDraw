# 操作方法
常にアップデートしているため、基本は古い情報である。

## 描画画面
- シミュレート: シミュレーション画面へ移動する。モデルの初回読み込みは時間がかかるため注意。
- リプレイ: `.config/replay`に保存されているリプレイを再生する。
  - 保存形式は`year-month-day_time_seed.toml`である。
  - 再生にはシード値を使用する。
- 障害物の設置: 障害物を設置する。
- 動物体について
  - `.config/object`にTOML形式で保存される。
  - 追加: 動物体を追加する。
  - 削除: 選択している動物体を削除する。
  - 編集: 選択している動物体を削除する。
- 列・出現地・目的地について
  - 列: 赤が始点・緑が終点
    - 列の線が障害物にかかると、シミュレーションを始めるときに、障害物を回り込む線に引き直す（描いた線は変えない）。障害物から列の幅（左右のぶれ幅 + 人の半径）だけ離す。引き直したらターミナルに「注意」が出る。
    - 規制線（動物体ごとに切り替え）でよくある2つの並びを作る。
      - なし（店に入る並び）: 最後尾の後ろから並ぶ。列に並ばない人は列を横切る。
      - あり（イベント会場の並び）: 列の左右に黄色い線（Space で消える）を引き、列には必ず始点から入る。ほかの人は線を回り込み、列を横切らない。始点と終点は開いている。
    - 規制線をくぐる（動物体ごと、列の線が無い動物体でも選べる）: その動物体の人は規制線を障害物と見なさず、中へ入って列を横切る。横切るときは規制線の無い列と同じく、優先度で譲り合う。建物の障害物は今までどおりよける。
    - 列の人の当たり判定の太さ: 列に並んでいる人の半径にこの値を足して、ほかの人を遠ざける。
    - 終点の開け閉め: 終点は「開いている時間」と「閉まっている時間」をくり返す（開いた状態から始まる。閉まっている時間が 0 ならずっと開いている）。閉まっている間、先頭の人は終点で待ち、後ろの人も詰まって止まる。
    - 受け入れ人数 / 受け入れ時間: 終点が開いている間に通れる速さ。例: 2 人 / 10 秒なら、5 秒の間隔で1人ずつ通る。人数が 0 なら制限なし。
  - 出現地・目的地の色は同じなため注意。

## シミュレーション画面
左上に操作方法が書いています。Godotのカメラ操作を基準としています。

- 右ドラッグ: 回転（カメラ軸）
- 中クリック: 回転（中央軸）
- 右クリック + WASD: 移動
- 右クリック + QE: 上下移動
- 中クリック + Shift: 平行移動
- ホイール: ズームイン・アウト
- `+` / `-`: 時刻を30分進める / 戻す
- Enter: 描画画面へ戻る
- Space: UI描画を切り替える

カメラ位置を固定することで、エディター画面に戻ってもカメラ位置を保持することができます。

## 設定画面
### 全体
- 乱数のシード: 0でランダム再生、0以外で固定再生
- 時刻: シミュレーションの時刻。太陽の位置を変える用。
- 出現範囲の横幅: 中心からの半径（横幅）
- 出現範囲の奥行: 中心からの半径（奥行）
- モデルの向き補正: 使用しているモデルの角度を補正する
- 障害物の高さ: 障害物の高さ
- 二本の経路: Trueだと、列を横切るルートと直進するルートを探査する。Falseだと、直進経路を探査する。
- 軽量3Dモデル: 人を軽いカプセルで表す。太さはぶつかる半径、高さは身長に合わせる。
- 3Dモデルのフォルダ: `名前_Walking.fbx`、`名前_Idle.fbx`を1人分として使う。FBXファイルを置くだけで読める。フォールバックで軽量3Dモデルになる。
- 人の身長: 人の身長。
- 床の画像: 床の画像。フォールバックで画像なしになる。
- 画角: カメラの画角

### 動物体の初期値
スクリプト依存なので設定画面を読んでください。
- 動きのスクリプト: 動物体の動きスクリプト。指定したスクリプトの項目は左の欄で変更する

### ぶつからない動き
- よけ方: 列に並んでいない人のよけ方。
  - AVM（Xu ら 2021）: 今の動き。下の「避ける相手を探す距離」〜「前の人との時間間隔」を使う。
  - 0.1.0 の動き: 近い人ほど強く押し返し、横へ回り込む力を足す（ゲーム的な動き）。「0.1.0: よけ始める距離」「0.1.0: よける強さ」だけを使う。比べるときはシードを固定して切り替える。
- 人の大きさ（半径）: 当たり判定に使う半径
- 避ける相手を探す距離: 歩行先の動物体を探す距離。先読みするのに必要。
  - 同じ向きの人には弱い補正
  - 向かってくる人には強い補正
- 避ける強さ: 避ける強さ
  - 同じ向きの人には二倍の補正をかける
- 避ける力の届き方:　
- 先読みの時間: どのくらい先読みするか
- 向き直る時間: 向きを変える時間。
- 前の人との時間間隔: 進む向きにいる人との隙間を、この時間で歩ける速さにする
- 列の人が道を譲る距離: 列の人と横切る人の隙間。

## JSON の出力（別のアプリへ渡す）
設定画面の「JSONを出す間隔」を 0 より大きくすると、シミュレーション中に1行1つの JSON を標準出力（ターミナル）へ流す。
Godot の起動表示なども同じ所に出るので、受け取る側は `{` で始まる行だけを読む。`print` の内容は Godot のログ（`user://logs/godot.log`）にも残る。

- `meta`: 始めに1回。`seed`（シード）、`interval`（間隔）、`camera`、`groups`（動物体の名前の配列）
- `camera`: カメラを動かしたときに出し直す。`t` と `camera`
- `frame`: 間隔ごと。`f`（1 から始まる通し番号）、`t`（始めてからの秒数）と `walkers`（`id`・`x`・`z`・`yaw`・`group`・`on_line`・`bbox`・`vis` の配列）
  - `bbox`: 画像の上の人の枠 `[左, 上, 幅, 高さ]`（px）。画面の外へはみ出した分も含む。画像に写っていない人（画面の外・カメラの後ろ）には `bbox` と `vis` が付かない
    - 枠は当たり判定の円柱（半径 × 身長）を囲むので、振った手足は少しはみ出す
  - `vis`: 見えている割合（0〜1）。「枠が画面の中にある割合」×「体の軸の 5 点のうち、障害物やほかの人に隠れていない割合」。0.2 刻みの目安
  - `group`: 動物体の番号（`meta` の `groups` の何番目か、0 始まり）
  - `on_line`: その動物体の列に並んでいる間だけ `true`（並びに行く途中は `false`）。`on_line` が `true` の人を `group` ごとに数えると、列の人数の正解になる
  - `id`: 人の番号。現れ直すと別の人として新しい番号になる
  - `x`・`z`: 床（XZ 平面）の位置。単位は m、描画画面の中心が原点
  - `yaw`: 向き。+Z から +X へ回る角度（ラジアン、-π〜π）。モデルの向き補正は含まない
- `camera` の中身: `pos`（位置 m）、`rot`（回転 ラジアン、YXZ の順）、`fov`（縦の画角 度）、`size`（画像のピクセル数）

```
{"camera":{"fov":70.0,"pos":[0.0,20.0,15.0],"rot":[-0.9,0.0,0.0],"size":[1280,720]},"groups":["レジの列"],"interval":0.1,"seed":7,"type":"meta"}
{"f":1,"t":0.1,"type":"frame","walkers":[{"bbox":[763.7,451.5,24.3,28.0],"group":0,"id":0,"on_line":true,"vis":1.0,"x":1.2,"yaw":1.571,"z":-4.05}]}
```

## データセットの書き出し（画像と正解）
設定画面の「データセットを書き出す」をオンにし、「JSONを出す間隔」を 0 より大きくしてシミュレートすると、間隔ごとに画像と正解を `./.config/dataset/日時_seedシード/` に書き出す。並びは MOTChallenge と同じ。

```
2026-11-12_070428_seed7/
  img1/000001.png …   画像（番号は JSON の f）
  gt/gt.txt           正解（MOTChallenge 形式）
  seqinfo.ini         フレームレート（1 ÷ 間隔）、枚数、画像の大きさ
  frames.jsonl        ターミナルに流すものと同じ JSON（meta・camera・frame）
```

- `gt.txt` の1行: `フレーム, 人の番号, 左, 上, 幅, 高さ, 1, 1, 見えている割合`
  - 人の番号は JSON の `id` + 1（MOTChallenge は 1 から始まる）
  - 画像に写っている人だけを書く。枠と見えている割合は JSON の `bbox`・`vis` と同じ
- 列の人数の正解は `frames.jsonl` の `on_line` から数える（`gt.txt` には無い）
- 書き出している間、操作説明と列の線・規制線は消える。Space で戻すと画像に映る
- 画像を1枚撮るたびに動きを一瞬止めるので、画像と正解は同じ瞬間のもの。止めても刻みの数は変わらないので、同じシードなら動きは同じ
- 同じ動きを別のカメラから撮る: カメラを動かして「位置固定」し、描画画面の「リプレイ」から同じリプレイを再生する。JSON の間隔と書き出しのオン・オフは、リプレイに記録した値ではなく今の設定を使う
- 画像の大きさはウィンドウの大きさ。そろえたいときはウィンドウの大きさを変えない
