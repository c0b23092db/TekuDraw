## 設定画面
### 全体
- 乱数のシード:　0でランダム再生、0以外で固定再生
- 時刻: シミュレーションの時刻を指定する。太陽の位置を変える用。
- 出現範囲の横幅: 中心からの半径（横幅）を指定する
- 出現範囲の奥行: 中心からの半径（奥行）を指定する
- モデルの向き補正: 使用しているモデルの角度を補正する
- 障害物の高さ: 障害物の高さを指定する
- 二本の経路: Trueだと、列を横切るルートと直進するルートを探査する。Falseだと、直進経路を探査する。
- 軽量3Dモデル: 人を軽いカプセルで表す。太さはぶつかる半径、高さは身長に合わせる。
- 3Dモデルのフォルダ: `名前_Walking.fbx`、`名前_Idle.fbx`を1人分として使う。FBXファイルを置くだけで読める。
- 人の身長: 人の身長を指定する
- 床の画像: 床の画像を指定する
### 動物体の初期値
- 動きのスクリプト: 動物体の動きを指定するスクリプトを指定する。指定したスクリプトの項目は左の欄で変更する

## シミュレーション画面
左上に操作方法が書いています。Godotのカメラ操作を基準としています。

- 右ドラッグ: 回転（カメラ軸）
- 中クリック: 回転（中央軸）
- 右クリック + WASD: 移動
- 右クリック + QE: 上下移動
- 中クリック + Shift: 平行移動
- ホイール: ズームイン・アウト
- `+` / `-`: 時刻を30分進める / 戻す
- Enter: 描画画面へ戻る
- Space: UI描画を切り替える

カメラ位置を固定することで、エディター画面に戻ってもカメラ位置を保持することができます。
